把学校照片做成地图（不需要写代码）

一、拍照
1. 每栋楼拍一张正对立面的照片：站在正前方、尽量远一点，镜头水平，整栋楼完整入镜，避开人脸和车牌。
2. 可选：拍一张 2:1 的 360 度全景图（手机相机的“球形全景/Photo Sphere”），作为背景天空。

二、处理照片
1. 把照片缩小到宽度 1024–2048 像素、体积 1MB 以内，保存为 jpg（手机相册或画图软件都能改尺寸）。
2. 把文件放进这个文件夹，命名为 main.jpg、left.jpg、right.jpg（对应主楼、左楼、右楼）。全景图命名为 sky.jpg。

三、修改 map.json
1. 每栋楼的 size 是 [宽, 高, 深]。立面照片的 宽:高 要和 size 对应面的 宽:高 一致，否则照片会被拉伸：
   主楼（facade 为 +z 或 -z 的面）：照片宽高比 = size[0] : size[1]
   侧楼（facade 为 +x 或 -x 的面）：照片宽高比 = size[2] : size[1]
   例：主楼照片 3000×1400（比例约 2.14），宽取 54，高就是 54÷2.14 ≈ 25。
2. 想用全景背景，在 map.json 最外层加一行："sky": "sky.jpg"
3. 想增加楼，复制一个 obstacles 里的 building 项，改 pos（中心点）、size、texture 和 facade（照片朝向 +x/-x/+z/-z）。
4. 重启 node server.js，在开始界面选这张地图。

没放照片的楼会显示默认的外墙样式，不会报错。
