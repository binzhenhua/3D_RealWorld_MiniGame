Multiplayer Shooting/Building - User Guide

I. File Structure (must be in the same folder)

server.js shooter-three.html package.json

maps/map_name/map.json and images (see maps/README.txt for details)

II. Startup (Read this first: Voice chat must use an HTTPS address)

1. Install Node.js (nodejs.org, select LTS).

2. Open the terminal in the folder: `npm install`, then `node server.js`

3. The terminal will print two addresses:

http://…:3000 For playing the game only (microphone not allowed, except localhost)

https://…:3443 For game + voice chat (friends please use this)

Friends on the same LAN should use the address printed in the terminal for "LAN friends".

4. The first time you open the HTTPS address, the browser will prompt "Insecure/Invalid certificate": Click "Advanced" → "Continue" (once per device and per browser). This is because the certificate is generated by the server itself, not issued by an official authority; the call content does not pass through the server, so there is no risk when using it within a local area network.

5. If you modify server.js or map.json, you need to restart the server; after modifying the webpage, press Ctrl+F5 to refresh.

6. If your computer's IP address changes (e.g., changed Wi-Fi), restarting the server will automatically regenerate the certificate.

7. To prevent warnings: use mkcert to generate the certificate, put cert.pem and key.pem into the certs/ folder (and delete auto.json inside),

Each friend's device also needs to have the mkcert root certificate installed. Ignore this if you don't want the hassle.

Voice Chat

On the start screen, check "Join Voice Chat." The browser will ask for microphone permission; click "Allow." After entering the game, press V to turn the microphone on/off (others cannot hear you when muted).

Spatial Voice: The sound gets quieter the farther away (beyond 45 units, inaudible), the sound comes from the direction of the speaker, headphones provide the best effect.

Cooperative Mode: Players in the room with voice chat enabled can hear each other. Versus Mode: Players can only hear each other; enemies cannot connect at all.

In the top left corner of the team list: 🎤 indicates the other player has voice chat enabled, 🔊 indicates the other player is speaking.

Voice chat is a direct connection between browsers (WebRTC); the sound does not pass through a server and is not recorded.

When there is no sound: 1) Both players must use HTTPS addresses and allow microphones; 2) Both devices must be on the same local area network (LAN), and the router must not have "AP isolation" enabled;

3) The computer firewall must allow browser communication; 4) Use headphones to avoid echo; 5) Press F12 to check the console for any red error messages.

This mode is only for LAN use; when deploying to the public internet, a TURN relay server (located in the ICE settings on the webpage) is required; otherwise, some direct network connections will not work.

III. Objectives (Shoot with a gun)

Bats: Small, fast, fly erratically; eliminate with one shot, earn 1 point.

Ghost: Semi-transparent, slowly floats towards the nearest player, can pass through walls, 2 shots to eliminate, 2 points.

Monster: Large, walks on the ground towards the nearest player, can be blocked by walls and bricks, 3 shots to eliminate, 3 points. A health bar appears above its head when it is injured.

After all waves are eliminated, the next wave spawns after 1.5 seconds. Currently, monsters will not attack players.

You can block monsters (except ghosts) by building walls with bricks, and they will also block bats.

III. Controls

Mouse: Rotate view (click on screen to enter, Esc to exit) WASD: Move Spacebar: Jump M: Mute

Inventory (bottom of screen): Press 1–9 or scroll wheel to switch

1 Gun 2 Brick 3 Plank 4 Glass 5 Stone 6 Door 7 Window 8 Pickaxe 9 Airplane

Gun: Left-click to fire

2–7 (with shovel): Left-click to build a corresponding block at the yellow frame; right-click to remove the block the crosshair is pointing to.

Door: A door is only 1 block high; to allow someone to walk through, 4 doors need to be stacked (approximately 3.2 meters tall). Doors stacked in the same column are considered one door; press E to open/close them together.

A door can be walked through when open, and bullets can pass through it; you cannot lock a door on yourself. Anyone can open or close a door.

Window: The window frame is opaque, the glass is semi-transparent, allowing you to see the other side, but people cannot pass through, although bullets can pass through (use glass blocks to block bullets).

8. Pickaxe: Left-click to remove the block the crosshair is pointing to (red box indicates a block that can be removed, gray box indicates a block built by someone else).

9. Plane: Transform into a small plane. Mouse controls flight direction (tilt/drag/turn), W/S accelerate/decelerate, A/D turn, left-click fire.

Speed ​​and altitude are displayed in the upper left corner (maximum 60). The plane will be blocked by buildings, walls, and bricks, and will not burrow into the ground; pressing 1–8 to switch back to other items will cause it to fall.

You cannot build blocks on the plane; others will see you as a plane.

E: Open/close the door the crosshair is pointing to (within 6 blocks).

Z: Undo the last block you built (when holding a shovel or pickaxe).

Building Protection (selected at the start screen, determined by the first person to enter the room; saved rooms use the settings from the save file; displayed in the upper left corner after entering the room):

On: You can only remove blocks you built; after the person who built the block leaves the room, anyone can remove their blocks.

**Closing:** Anyone can dismantle any block built by anyone else (suitable for friends building together). Blocks in red boxes are dismantlable.

All blocks can be stood on, used as shields, and blocked by bullets; each room can have a maximum of 4000 blocks.

IV. Saving

Each room automatically saves its work: approximately every 2 seconds after building/dismantling blocks, and also when everyone exits or closes the server (Ctrl+C).

Saves are located in the `saves/` folder, one file per room. Re-entering with the same room number will preserve your building.

Rooms with saves will use the map from those saves (so change your room number if you want to change maps).

"My building" is identified by a browser identifier: changing your browser or clearing your browser data will remove your previously built blocks (they become someone else's, and anyone can dismantle them if the person who built them isn't present).

Backup: Copy the `saves/` folder; to clear a room: shut down the server, delete the corresponding file, and restart.

When deploying to a cloud server, `saves/` must be placed on a persistent disk; otherwise, redeployment will result in data loss.

The start screen allows you to upload an avatar, select a map, choose the mode (cooperative/versus), and the number of monsters per wave.
